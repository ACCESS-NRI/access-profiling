# Parsers

Here you will find the base class of all the parsers, the kinds of data a parser can return, and the functions
that work on them. See [Logs and metrics](../user-guide/logs-and-metrics.md) for how the logs are read.
The parsers of the logs of the ACCESS models are documented under [Log formats](log-formats.md), and those of
Payu's and Cylc's records under [Payu](payu.md) and [Cylc and Rose](cylc-rose.md).
