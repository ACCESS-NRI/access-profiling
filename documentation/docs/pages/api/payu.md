# Payu

The manager and the application types for applications run with [Payu](https://payu.readthedocs.io/en/stable/):
the base class of their configurations, the components they are put together from and the submodels that arrange
them, and the parser of Payu's job files. [Experiments with Payu](../access/payu.md) describes how they are used.
