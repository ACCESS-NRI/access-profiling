# Applications

An application is what a study profiles: which components it runs, how a layout is written into its
configuration files and read back out of them, and which profiling logs it writes. The application types of the
workflow engines of the ACCESS models are documented under [Payu](payu.md) and [Cylc and Rose](cylc-rose.md), and
the ACCESS models themselves under [Models](models.md).
