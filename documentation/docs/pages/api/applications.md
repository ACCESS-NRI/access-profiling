# Applications

An application is what a study profiles. It knows how the application is parallelised, which files need to be
edited to run a parallelisation layout, and which profiling logs it writes. The application types of the
workflow engines of the ACCESS models are documented under [Payu](payu.md) and [Cylc and Rose](cylc-rose.md), and
the ACCESS models themselves under [Models](models.md).
